# Data Science Coursework Assignments

Two short lab assignments completed as part of IBM's Data Science coursework (via Coursera / IBM Skills Network).

## 1. Data Science Tools and Ecosystem (`DataScienceEcosystem.ipynb`)

A short introductory notebook covering:
- Popular data science programming languages (Python, R, Julia, Java, Scala, SQL)
- Commonly used data science libraries (NumPy, Pandas, Matplotlib, Plotly, Seaborn)
- Popular data science tools (Jupyter Notebook, RStudio, VS Code)
- Basic arithmetic expression evaluation in Python (e.g. converting minutes to hours)

## 2. Extracting and Visualizing Stock Data (`Final Assignment.ipynb`)

A guided lab extracting and visualizing historical stock and revenue data for **Tesla (TSLA)** and **GameStop (GME)**:
- Extracted historical stock price data using the `yfinance` library
- Web-scraped quarterly revenue data for both companies using `requests` and `BeautifulSoup`
- Cleaned the scraped revenue data (removed currency symbols/commas, dropped nulls)
- Built dual-panel interactive charts (share price + revenue over time) using Plotly

## Tools & Libraries

Python, Pandas, yfinance, BeautifulSoup, Plotly

## Note

These are coursework lab exercises (IBM Data Science / Python Project for Data Science courses), not independent end-to-end projects — useful for demonstrating foundational data extraction and visualization skills, but distinct in scope from the larger capstone-style projects in other repos.
